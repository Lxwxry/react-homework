1. Как правильно добавлять элементы в массив?

Использовать оператор spread (...), чтобы создать новый массив:

setNumbers([...numbers, 4]);

2. Как правильно изменять элементы в массиве?

Использовать метод map(), который создаёт новый массив с изменённым элементом:

setNumbers(numbers.map((elem, index) =>
    index === 1 ? 100 : elem
));

3. Как правильно удалять элементы из массива?

Использовать метод filter(), который создаёт новый массив без нужного элемента:

setNumbers(numbers.filter(elem => elem !== 2));

4. Как правильно добавлять элементы в массив объектов?

Использовать оператор spread (...) и добавить новый объект:

setUsers([...users, { id: 3, name: 'Максим' }]);

5. Как правильно изменять элементы в массиве объектов?

Использовать map() для создания нового массива и spread (...) для копирования изменяемого объекта:

setUsers(users.map(user =>
    user.id === 2
        ? { ...user, name: 'Александр' }
        : user
));

6. Как правильно удалять элементы из массива объектов?

Использовать filter() для создания нового массива без нужного объекта:

setUsers(users.filter(user => user.id !== 2));

Вывод: В React нельзя напрямую изменять массивы и объекты, хранящиеся в состоянии. Нужно создавать их копии и передавать в setState.
